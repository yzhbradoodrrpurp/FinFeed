# 邮件提醒配置与运行

入口：登录 → 我的账户 → 邮件提醒。每个账户独立绑定并验证邮箱，独立设置总开关、NFP、PCE、十年美债、巨鲸及 News 开关。默认总开关关闭。验证码只保存哈希，10 分钟有效，最多尝试五次，每分钟最多发送一次。

## 配置步骤

1. 创建 [Resend](https://resend.com/docs/dashboard/domains/introduction) 账户，添加自己控制的发信域名，按面板要求配置 DNS，等待域名验证完成。没有自有域名时，测试发件域的收件人限制不能用于给所有用户正式发信。
2. 创建具有发送权限的 API key。在 Render 后端服务 Environment 中配置：
   - `RESEND_API_KEY`：Resend API key。
   - `FINFEED_EMAIL_FROM`：已验证域名下的发件邮箱，例如 `alerts@example.com`，只填邮箱，不加显示名称。
   - `FINFEED_NOTIFICATION_CRON_TOKEN`：独立随机字符串，至少 32 字符。可在本机运行 `python3 -c 'import secrets; print(secrets.token_urlsafe(32))'` 生成。不要提交到 Git 或贴入聊天。
3. 重新部署后端。在外部定时服务中设置每分钟执行一次 HTTP POST：
   - URL：实际 **Render 后端域名** 的 `/api/notifications/tick`，不是 Vercel 静态站点域名。
   - Header `Authorization: Bearer <上一步生成的调度密钥>`。
   - Header `Content-Type: application/json`。
   - Body：`{}`。
   - 不把密钥放进 URL。将调度密钥保存在定时服务的加密配置中。
4. 在网站“我的账户”输入收件邮箱，发送验证码并验证，选择提醒开关，开启总开关，保存。
5. 检查定时服务日志：202 表示任务已接受，403 表示密钥不匹配，503 表示邮件服务未配置。202 不代表邮件已送达。Resend 后台可检查实际送达、退信等情况。登录后的 `GET /api/notifications` 返回本人队列计数；`sent` 表示渠道已接受，不能等同收件箱送达。

当前实现尚未配置生产发件凭据；自动化测试使用模拟邮件渠道，没有发送真实邮件。首次上线必须完成真实邮箱验证和一次实际触发验收。

## 提醒口径

- **NFP / PCE**：按 BLS / BEA 官方日历，在发布前 24 小时窗口提醒一次；到计划发布时刻再提醒一次。计划时刻提醒明确区别于实际数据已经取得。取得新的完整数据对应期后另发数据更新邮件。启用时距发布不足 24 小时，首次检查会补发即将发布提醒。来源故障可能延迟提醒；发布时刻补发窗口为六小时。
- **十年美债**：目前沿用 H.15 / FRED DGS10 日度十年恒定期限收益率。比较连续成功读取的数据，在从低于预警线到达到/超过，或从达到/超过回落至下方时发送。默认 5.1%，可修改。首次读取或修改阈值建立基线，不把当前已在线上的状态当作新穿越。**不是实时盘中预警**。
- **巨鲸**：每小时检查网站现有机构的最新 13F 报告及修订。邮件附持仓报告期、申报时间和 SEC 原文件；不能视为实时交易。
- **News**：每小时检查收件人自己 Watchlist 中的 Earnings Calls 和 SEC Filings。沿用页面的最近两个已发布季度筛选口径。新增股票首次成功读取建立基线，之后的新条目才通知。无新内容不发邮件。

## 调度、缓存与失败处理

任务在服务器后台执行，网页无需打开。宏观检查与公司数据抓取分开运行，分别最多两个源任务并发；相同数据源按数据库租约合并。正常源间隔一小时，NFP/PCE 临近发布时检查间隔一分钟，失败五分钟后重试。复用已有成功市场缓存，发布前五分钟至发布后半小时内加快宏观源刷新。上游发布、外部定时器、平台唤醒、抓取和邮件渠道都可能产生延迟，不能保证整点零延迟。

[Render 免费实例](https://render.com/docs/free)会休眠，必须使用独立于网页的外部调度；不要依赖浏览器定时器。实际准点程度受平台可用性影响。外部调度与 Resend 的额度、限制以各自账户面板为准。

订阅、已见事件和发件队列持久化到私人数据库。新内容入队和游标更新在同一事务中完成，唯一事件键防止重复排队；发送使用固定 [Resend Idempotency-Key](https://resend.com/docs/dashboard/emails/idempotency-keys)。失败指数退避，超过 23 小时停止重试，避免越过渠道 24 小时去重窗口重发。故障不会把旧数据当作新事件。关闭类别或总开关、解绑、换邮箱会取消相应待发邮件；已经提交到邮件渠道的消息无法撤回。

账户与通知数据库可用性是执行前提。没有配置发送服务时不启动监控，不额外抓取市场数据。监控不开启网站登录链路中的同步数据请求。
