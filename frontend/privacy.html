FinFeed Mail 隐私说明

更新日期：2026-10-09

FinFeed Mail 是 FinFeed 的邮件提醒功能，用于向已验证并开启提醒的用户发送市场事件通知。

Google 授权范围

仅由运营者授权专用 Gmail 发件账户，申请 gmail.send 权限以发送邮箱验证码和通知。该授权不用于读取收件箱、联系人或附件。收件用户无需授权自己的 Google 账户。

使用与存储的数据

服务器保存发件 OAuth 凭据，用于更新访问令牌和调用 Gmail 发信接口；凭据不进入公开前端或代码仓库。用户的收件邮箱、验证码哈希、提醒偏好、已检查事件和邮件队列保存在后台数据库。News 提醒会使用该用户在 FinFeed 中保存的观察列表。

Google 处理发送给 Gmail API 的收件地址、邮件标题及正文。FinFeed 的托管服务和数据库服务处理运行所需的数据；定时服务仅调用受专用密钥保护的检查接口，无需取得 Gmail 授权凭据。

控制与删除

用户可在“我的账户”关闭提醒、关闭单个类别或解绑邮箱。解绑会删除绑定设置和事件游标，并取消待发邮件；已有邮件队列记录不会因此全部删除，已提交给邮件渠道的消息无法撤回。如需进一步清理数据，请联系运营者。

发件账户所有者可以在 Google 账户的第三方连接管理中撤销 FinFeed Mail 授权；撤销后发信服务将无法继续使用该授权。

用途限制

Google 授权和邮件数据仅用于上述发信与故障排查，不用于广告定向或模型训练。FinFeed Mail 对 Google API 数据的使用与转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。
