# 股票交易记录

把每笔实际操作及其决策原因直接存入本目录。除本 README 外，本目录内容已加入仓库根目录的 `.gitignore`，不提交个人交易记录。

建议每笔操作单独一个 Markdown 文件，命名为 `YYYY-MM-DD-股票代码-操作.md`，例如 `2026-09-29-SMCI-buy.md`。同一天同一股票有多笔操作时，在文件名末尾加序号。

记录时区、市场和货币，区分下单时间与成交时间。若只是考虑交易但尚未执行，明确标注“计划”，不要混入实际成交记录。每次复盘可追加带日期的段落，保留当时的原始判断。

可复制以下模板，在本目录新建记录文件：

```markdown
# YYYY-MM-DD｜股票代码｜买入/卖出/加仓/减仓

- 状态：计划 / 已成交 / 已撤单
- 市场与币种：
- 下单及成交时间（含时区）：
- 数量、成交价、费用：
- 操作后仓位：

## 当时的决策

- 投资逻辑与时间范围：
- 事实依据（数据截至时间及原始来源链接）：
- 我的推断、预期与关键假设：
- 为什么现在操作、为什么是这个仓位：
- 反方证据及主要风险：
- 什么情况会推翻原判断：

## 后续复盘

- 复盘日期：
- 实际进展与原判断的差异：
- 是否调整计划及原因：
```

`.gitignore` 只能防止正常的 Git 跟踪，不提供加密；不要在日志中写账户密码、令牌或完整账户号码。
